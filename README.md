## 🌟 About The Project
**BookBot** is a command-line utility designed to perform fundamental text analysis on a book's contents. This project was my first venture into structured software development, completed as part of the **Boot.dev** curriculum.

The primary goal of this project was to learn and practice core programming concepts such as:
* File I/O (reading and processing text files).
* Data manipulation (counting words, characters, and analyzing frequency).
* Functional programming and modular design (as seen in `main.py` and `stats.py`).

**"It takes a text file as input, calculates the total word count, and generates a report detailing the frequency of every letter of the alphabet."**

### Key Features
* **Word Count:** Quickly calculates the total number of words in the provided text file.
* **Character Frequency:** Generates a detailed report of how many times each character/letter appears (case-insensitive).
* **Report Generation:** Prints a clear, sorted, and easy-to-read statistical analysis to the console.
